奥迪仪表盘，终于能显示 CarPlay 导航了

原厂 CarPlay 导航只能挤在中控屏，仪表盘还在用原车地图。这个开源项目把 iPhone 的导航投进了 Virtual Cockpit，转向箭头、车道引导、电话页都跟着来了——而且免费。

很多奥迪车主都遇到过这个憋屈时刻：iPhone 插上 CarPlay，高德或百度在中控屏上跑得挺好，抬头一看，方向盘后面那块更贵的虚拟座舱，还停在原车地图上——两条导航，各说各话。

能不能把手机的导航，直接投进仪表盘？

能。有个开源项目做到了，叫 MHI2Q-CarPlay-AltScreen，当前版本 V3.8 Fix1，代码全部公开在 GitHub（yuedizhibo/MHI2Q-CarPlay-AltScreen）。上线一个月左右，已经有 400 多颗 star。

它做的事，一句话就能说清

项目面向奥迪 MHI2Q 平台，把 CarPlay 的「第二屏」（AltScreen）原生导航画面，显示到 Virtual Cockpit 上。

注意，不是把中控整个画面镜像过去，是 CarPlay 原生的第二屏。iPhone 里的苹果地图、高德、百度，都能直接显示在仪表盘上，跟随导航更新，还能用方向盘左侧的滚轮缩放地图。

不止是把地图搬过去

除了第二屏地图，它还顺手解决了一堆原车的「别扭」：

  • 转向箭头和车道引导（RGI）。原车连 CarPlay 导航时，仪表上不显示 iPhone 的转向箭头，现在有了，还带车道引导。
  • 仪表电话页。原车连上 CarPlay 后，电话页只显示一句「iPhone 处于 Apple CarPlay 模式」。现在像蓝牙电话一样，显示来电、拨号、通话计时、最近通话和收藏，方向盘上就能接听、挂断、静音。
  • 底部信息栏多一行「路名 | 预计到达时间」。
  • 手机转向卡片，在 B9、Q7 的大地图视图显示。
  • 性能不拖后腿：颜色转换从 CPU 挪到 GPU，整机 CPU 占用从约 80% 降到约 20%。

无线 CarPlay 也支持，实测君用 M2Pro 无线盒子（最新内测固件）能跑第二屏、RGI 和滚轮缩放。

门槛和代价，提前说清楚

这不是插上就能用的东西，有几道门槛：

  • 平台只有 MHI2Q，不支持 MHI2；固件必须是 AUG22，安装脚本会自己核验，不是就拒绝。
  • 中国区固件已实车验证；部分欧洲区固件有人反馈能用；US 等其他地区不保证，可能有未知 bug。
  • iPhone 推荐 iOS 26。低于 iOS 18，百度地图可能不出画面，高德可能比例异常。
  • 装之前得先装上游的 jilleb/mib2-toolbox（走红色菜单），再通过绿色菜单的 MQBCoding → Update Toolbox 合并本项目的覆盖包。

更要紧的是风险：它会写车机系统文件和防火墙规则，有黑屏、故障、影响保修的可能。作者在 README 里反复强调，出了问题自己担。好处是它带安全安装、恢复、救车模式和开机日志，实在翻车了也能往回退。别在开车的时候折腾这些。

它是免费的，别花钱买

这里要单独说一句。

项目从 V3.7 起源码全部公开，免费下载。V3.8 起，原创部分改用 PolyForm Noncommercial 加附加条款：个人可以免费使用、研究、修改、免费转发，但禁止售卖。就算帮人安装收费，每台车每次也不得超过 100 块。基于 Luka 和 Allemon 的 Java HMI、RGI 部分，继续按 GPL-3.0 发布。

作者在 README 里贴了一份严正声明：有网站把项目改头换面，抹掉作者署名和许可证，挂出去标价 200 美元，还要求登录或积分才能下载。

值不值得折腾

如果你正好是 MHI2Q 的车主，又常年用 CarPlay 导航，这个项目大概是目前把手机导航搬进奥迪仪表盘最完整、也最克制的一个方案：不推翻原车，只补上原厂没给的那块屏。

它最打动我的，其实不是那些技术细节，而是作者那句话——「本项目最初就是基于我们自己的车辆和日常使用需求进行开发」。自己的车，自己想要什么功能，就自己动手补上，再免费放出来。
